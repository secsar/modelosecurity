# Resource guide

Modelo Security resources connect requirements, modeling, decisions, and supporting evidence.

| Resource | Purpose |
| --- | --- |
| [Review workflow](review-workflow.md) | Organize a review from requirements through evidence |
| [Review package specification](review-package.md) | Define the structured input and validation rules |
| [Security modeling](https://github.com/secsar/security-modeling) | Specify permitted behavior and security properties |
| [Threat modeling](https://github.com/secsar/threat-modeling) | Analyze failure scenarios and treatment decisions |
| [StephSec Research](https://github.com/secsar/stephsec-research) | Develop research questions, experiments, and evidence interpretation |

Keep detailed artifacts in their owning repository and link the version used in a review. A passing structural check establishes consistency of the submitted records within the tool's documented limits; it does not establish security effectiveness.
