# Development roadmap

## Available

Local evidence-readiness validation and Markdown/JSON reporting; synthetic fixtures with deliberate gaps; meaningful negative tests; cloud, AI, and delivery review playbooks; versioned references to companion models.

## Next milestones

| Milestone | Deliverable | Acceptance condition |
| --- | --- | --- |
| Interoperability | Companion-repository import/export examples | IDs survive a documented round trip |
| Evidence review | Scoped reviewer decisions with expiry | Expired/revoked assessments cannot silently satisfy readiness |
| Execution provenance | Reproducible evaluation manifests | Inputs, configuration, and output trace to a run |
| Broader examples | Complete synthetic review packages | Successful and rejected decisions are reproducible |

These are development directions, not promised dates or available hosted services. No cloud connector, continuous scanner, autonomous remediation, or compliance certification is part of this public prototype.
